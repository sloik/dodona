# 0003. Someone outside can write a provider from the documents alone

A person or agent who has never spoken to the authors can plug in their own decision format, checker or compiler using only what is in the repository.

## Criteria

| # | Criterion | Gate | Checked by |
|---|---|---|---|
| 1 | Every message of every capability has a schema and a worked example | hard | Not yet covered |
| 2 | The configuration, the lock and policy each have a reference | hard | Not yet covered |
| 3 | An agent with no other context writes a working provider for a tool the authors did not choose | deferred | Not yet covered; needs a kernel |
